# @cdk8s-charts/solace

Fully typed [cdk8s](https://cdk8s.io/) constructs for the
[Solace PubSub+ Software Event Broker](https://dev.solace.com) Helm charts.

Wraps the three upstream Solace charts, all sharing the same values schema:

| Construct | Chart | Topology | Default size | Default storage |
|-----------|-------|----------|--------------|-----------------|
| `PubsubPlus` | `pubsubplus` | single-node non-HA | `prod1k` | `30Gi` |
| `PubsubPlusDev` | `pubsubplus-dev` | minimum footprint single-node (dev) | `dev` | `10Gi` |
| `PubsubPlusHa` | `pubsubplus-ha` | HA redundancy group (Primary/Backup/Monitor) | `prod1k` | `30Gi` |

The Solace advanced event broker streams events over AMQP, JMS, MQTT, REST,
SMF, and WebSocket. Brokers in multiple locations can be linked into a Solace
[event mesh](https://solace.com/what-is-an-event-mesh/) to dynamically share
events across cloud, on-prem, and hybrid environments.

- Artifact Hub: [pubsubplus](https://artifacthub.io/packages/helm/solace/pubsubplus) ·
  [pubsubplus-dev](https://artifacthub.io/packages/helm/solace/pubsubplus-dev) ·
  [pubsubplus-ha](https://artifacthub.io/packages/helm/solace/pubsubplus-ha)

## Features

- Strongly typed `Props` (inputs) and `Exports` (outputs) — no hardcoded strings.
- Three constructs sharing one typed values model and a common base class.
- Convenience knobs for the most common chart values: `redundancy`, `size`,
  `systemScaling`, `adminPassword` / `adminPasswordSecretName`, `timezone`,
  `tls`, `serviceType`, `storage`, and `insights`.
- Deep-mergeable `values` overrides for every other Helm value.
- Exposes the canonical broker ports (SMF, SEMP, AMQP, MQTT, REST) for
  cross-service wiring.

## Usage

### Single-node (production-tier)

```typescript
import { App, Chart } from 'cdk8s';
import { PubsubPlus } from '@cdk8s-charts/solace';

const app = new App();
const chart = new Chart(app, 'my-chart', { namespace: 'messaging' });

const broker = new PubsubPlus(chart, 'pubsubplus', {
  namespace: 'messaging',
  size: 'prod1k',
  serviceType: 'LoadBalancer',
  storage: { persistent: true, size: '30Gi' },
  // Recommended for production: reference an existing Secret
  // (key: username_admin_password) instead of a plain-text password.
  adminPasswordSecretName: 'solace-admin-secret',
});

console.log(broker.exports.host); // 'pubsubplus'
console.log(broker.exports.smfPort); // 55555
console.log(broker.exports.sempPort); // 8080
app.synth();
```

### Development (minimum footprint)

```typescript
import { App, Chart } from 'cdk8s';
import { PubsubPlusDev } from '@cdk8s-charts/solace';

const app = new App();
const chart = new Chart(app, 'my-chart', { namespace: 'messaging' });

new PubsubPlusDev(chart, 'pubsubplus-dev', {
  namespace: 'messaging',
  serviceType: 'ClusterIP',
});
```

### HA with Insights and TLS

```typescript
import { App, Chart } from 'cdk8s';
import { PubsubPlusHa } from '@cdk8s-charts/solace';

const app = new App();
const chart = new Chart(app, 'my-chart', { namespace: 'messaging' });

new PubsubPlusHa(chart, 'pubsubplus-ha', {
  namespace: 'messaging',
  size: 'prod10k',
  insights: {
    enabled: true,
    apiKey: process.env.SOLACE_INSIGHTS_API_KEY!,
    site: process.env.SOLACE_INSIGHTS_SITE!,
    tags: 'env:prod,region:us-east',
  },
  tls: {
    enabled: true,
    serverCertificatesSecret: 'solace-tls',
  },
});
```

## Props

| Prop | Type | Required | Purpose |
|------|------|----------|---------|
| `namespace` | `string` | yes | K8s namespace |
| `redundancy` | `boolean` | no | HA (Primary/Backup/Monitor); defaults per chart |
| `size` | `'dev' \| 'prod1k' \| 'prod10k' \| 'prod100k'` | no | Scaling tier; defaults per chart |
| `systemScaling` | `SolaceSystemScaling` | no | Fine-grained scaling; overrides `size` |
| `adminPassword` | `string` | no | Plain-text admin password (autogenerated if omitted) |
| `adminPasswordSecretName` | `string` | no | Existing Secret holding the admin password |
| `timezone` | `string` | no | tz database timezone name; default UTC |
| `tls` | `SolaceTlsProps` | no | TLS toggle |
| `serviceType` | `'ClusterIP' \| 'NodePort' \| 'LoadBalancer'` | no | Service exposure; default `LoadBalancer` |
| `storage` | `SolaceStorageProps` | no | Storage knobs |
| `insights` | `SolaceInsightsProps` | no | Solace Insights agent config |
| `chart` | `string` | no | Helm chart name/ref; defaults to the wrapped chart |
| `repo` | `string` | no | Helm repository URL |
| `version` | `string` | no | Helm chart version pin; defaults to `3.10.0` |
| `values` | `DeepPartial<SolaceValues>` | no | Raw Helm value overrides |

## Exports

| Export | Type | Value |
|--------|------|-------|
| `host` | `string` | Service DNS name |
| `smfPort` | `number` | Solace SMF port (default `55555`) |
| `sempPort` | `number` | SEMP management API port (default `8080`) |
| `amqpPort` | `number` | AMQP port (default `5672`) |
| `mqttPort` | `number` | MQTT port (default `1883`) |
| `restPort` | `number` | REST port (default `9000`) |
| `serviceType` | `string` | Resolved service type |
